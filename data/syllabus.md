# B.Tech CSE — Semester 5 Syllabus (2025-26 Batch)

## CS501 — Artificial Intelligence
**Credits:** 4 | **Contact Hours:** 4/week
- Unit 1: Introduction to AI, Intelligent Agents, Problem Solving by Search (BFS, DFS, A*)
- Unit 2: Knowledge Representation, Propositional & First-Order Logic
- Unit 3: Reasoning Under Uncertainty, Bayesian Networks
- Unit 4: Machine Learning Foundations — Supervised, Unsupervised Learning
- Unit 5: Neural Networks, Introduction to Deep Learning and NLP
**Textbook:** Russell & Norvig, "Artificial Intelligence: A Modern Approach", 4th Edition
**Internal Assessment:** 2 tests (15 marks each) + Assignment (10 marks)

## CS502 — Database Management Systems
**Credits:** 4 | **Contact Hours:** 4/week
- Unit 1: ER Model, Relational Model, Normalization (1NF–BCNF)
- Unit 2: SQL — DDL, DML, Joins, Subqueries, Views
- Unit 3: Transaction Management, ACID Properties, Concurrency Control
- Unit 4: Indexing, Query Optimization
- Unit 5: NoSQL Databases, Introduction to Distributed Databases
**Lab Component:** MySQL/PostgreSQL lab, 2 hours/week, 30 marks

## CS503 — Computer Networks
**Credits:** 3 | **Contact Hours:** 3/week
- Unit 1: OSI & TCP/IP Models, Physical Layer
- Unit 2: Data Link Layer — Framing, Error Detection, MAC Protocols
- Unit 3: Network Layer — IP Addressing, Routing Algorithms
- Unit 4: Transport Layer — TCP, UDP, Congestion Control
- Unit 5: Application Layer Protocols — HTTP, DNS, FTP, Email

## CS504 — Software Engineering
**Credits:** 3
- Unit 1: SDLC Models — Waterfall, Agile, Scrum
- Unit 2: Requirements Engineering, SRS Documentation
- Unit 3: Software Design — UML Diagrams, Design Patterns
- Unit 4: Software Testing — Unit, Integration, System Testing
- Unit 5: Software Project Management, Estimation Techniques

## CS505L — AI & DBMS Laboratory
**Credits:** 2
- Implementation of search algorithms, Prolog-based logic programs
- SQL query practice, stored procedures, triggers
- Mini-project: Build a small AI or database-driven application

## Elective — CS5E1 Machine Learning (Open Elective)
**Credits:** 3
- Regression, Classification, Decision Trees, SVM, Clustering, Model Evaluation Metrics
